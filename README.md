# Sky-Japanese-Room
Sky Japanese Room adalah platform belajar bahasa Jepang yang dirancang khusus untuk pemula persiapan JLPT N5. Dengan materi yang mudah dipahami, latihan interaktif, serta pembelajaran yang menyenangkan, Sky Japanese membantu pelajar mempelajari hiragana, katakana, kanji dasar, kosakata, tata bahasa, dan percakapan sehari-hari secara bertahap.
